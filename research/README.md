# Research

How to improve the system: where it should go, why it is built this way, what
was tried and what the evidence showed. The system an agent follows while
charting is in [prompts/](../prompts/README.md).

Start here:

- [roadmap/](roadmap/README.md): product direction, milestones and current state.
- [rule-history.md](rule-history.md): which user correction or study produced each charting rule.
- [song-analysis-framework/DESIGN.md](song-analysis-framework/DESIGN.md) and [phrase-rhythm-framework/DESIGN.md](phrase-rhythm-framework/DESIGN.md): why each framework exists, calibration and results.

The other folders are studies, corpora and training runs. Their scripts may use
paths from before the repository was reorganized; translate them with
[local-path-map.md](../prompts/shared/local-path-map.md).

Research may link to prompts. Prompts reach research only through
[references.md](../prompts/shared/references.md).
