# Reusable chart-derived phrase evidence API

`evidence_from_chart(chart_ref, digest, start, end, audio_ref=None, audio_step='1/4', audio_tolerance_ms=25)` reads an exact half-open beat range from authoritative immutable IR, groups new heads by exact chart-relative time, derives kinds and hold duration through the stored global tempo map, excludes positions/line effects, and registers a bounded compiler-compatible record. It returns only the cache reference and counts. Imported per-line BPM has already been decoded into exact IR seconds; offset is applied only when deriving audio-relative timestamps, never to rhythmic duration.

The record contains numeric beat conveniences and exact rational mirror fields (`beat_start_exact`, `beat_end_exact`, per-event `beat_exact`, `chart_seconds_exact`, `audio_seconds_exact`, `sustained_durations_exact`). Holds crossing the start appear under `carry_in_sustains`, not as fabricated new heads. Heads crossing the end retain full source duration in evidence; motif selection may cap generated duration deliberately. Counts remain objects/roles, not identified instruments or fingers. Carry-in is evidence for agent decisions; compiler scheduling uses the actual target chart's existing annotated notes.

Optional audio uses the separately cached `audio_analysis` module: `load_audio_analysis(audio_ref)` and `match_register_peaks(record,audio_seconds,tolerance_ms)`. Candidate beats form an explicit exact lattice under the chart tempo/offset, and retain nearest measured AUDIO-relative peaks. No optional audio dependency is imported by chart-only extraction. Absence of audio leaves candidate array empty. The lattice/peak match does not identify instruments or justify attacks by itself.

Bounds: up to1000 new heads/groups and1000 carry-in holds,2000 candidate lattice points,256KiB registered record. Oversized requests reject with phrase-splitting repair advice; no silent truncation. Exact settings/source model digest key the evidence cache; repeated requests are deterministic cache hits. Stale digest rejects before extraction. Tests cover mixed source line BPM, nonzero offset, tempo-crossing durations, simultaneous role grouping, carry-in exclusions, boundaries, coordinate absence, repeated cache use and public protocol orchestration into a compact target phrase.
