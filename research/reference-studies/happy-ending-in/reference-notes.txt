SCROLL SPEED — THE MAIN CORRECTION
The reference's ordinary official speed 2.3 converts to PhiChain native speed 10.35.
Formula is native_speed = official_speed / 2 * 9, from phichain-format/src/official/into_phichain.rs.
PhiChain scroll distance uses viewport_height * 120/900 * integrated native speed,
from phichain-game/src/core.rs. Therefore 10.35 = 1.38 screen-heights/second.
Override currently uses native speed 4.6 = 0.613333 screen-heights/second.
Reference ordinary scroll is 2.25 times faster. Override is only 44.44% of this baseline.
At the same travel distance, reference approach time is 44.44% of Override's.
For a fixed horizontal line and a half-screen approach only: 0.362s vs 0.815s.
These normalized times are NOT measured visibility durations: line origin, rotation,
opacity, side, note extent and speed transitions affect actual reading time.
1175 / 1217 notes (96.55%) have effective speed 2.3 at judgment.
Other effective speeds at judgment: 2.1 (31 notes), 2.0 (3), 1.0 (6), 0.0 (2).
Holds: official note.speed is absolute; do not multiply it by line speed again.
999/0/negative line speeds also exist; they are special events, not baseline speed targets.
Prior Override speed was not calibrated against this reference; structural validity did not establish good reading feel.
